The implementations are cleanly separated into **C** and **C++** at the root level, demonstrating core automata theories (DFA/NFA validation, Moore/Mealy machines, complement computation, and binary mathematics).

### Brief Description of Conversion Process

Each C++ assignment was refactored into clean, standardized C:
- Dynamic/generic STL containers (`std::vector`, `std::set`, `std::map`, `std::queue`) were replaced with optimized C constructs (e.g., bitmask representations for NFA-to-DFA sets, simple static arrays for stacks/queues).
- Stream-based I/O (`std::cin`, `std::cout`) was replaced with standard input/output (`scanf`, `printf`).
- High-level C++ classes, namespaces, and standard containers were eliminated to use pure, compile-ready standard C code.

## ⚡ How to Compile & Run

### Prerequisites
Ensure you have `gcc` (for C programs) and `g++` (for C++ programs) installed on your system.

### Compilation Commands

1. **For C programs:**
   ```bash
   gcc C/<assignment_folder>/<filename>.c -o output
   ./output
   ```
   *Example:*
   ```bash
   gcc C/02_At_Least_One_Zero/at_least_one_zero.c -o output
   ./output
   ```

2. **For C++ programs:**
   ```bash
   g++ CPP/<assignment_folder>/<filename>.cpp -o output
   ./output
   ```
   *Example:*
   ```bash
   g++ CPP/01_At_Least_One_Zero/at_least_one_zero.cpp -o output
   ./output
   ```
